# Computer Communication Networks (CCN) Lab - GNS3 Projects

This repository contains GNS3 project files for the Computer Communication Networks (CCN) laboratory experiments.

## 📂 Repository Structure

- **`ccn_lab_exp6/`**: Contains the GNS3 project file and associated configurations for Experiment 6.
- **`CCN_LAN_EXP7/`**: Contains the GNS3 project file and associated configurations for Experiment 7 (LAN setup).

## 🚀 Getting Started

To open and run these experiments, you will need:
- [GNS3](https://www.gns3.com/) installed on your system.
- Necessary appliance images (routers, switches, etc.) imported into GNS3 as required by the projects.

### How to use
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/ATHARVA316-DEV/ccn_lab_GNS3.git
   ```
2. Open GNS3.
3. Go to **File** > **Open Project**.
4. Navigate to the cloned directory and select the respective `.gns3` file inside the experiment folders (e.g., `ccn_lab_exp6.gns3`).

## 📝 Notes
- Ensure that the path to the project files does not break any local path dependencies in GNS3.
- If an image is missing, GNS3 will prompt you to provide an alternative appliance.
